# 阅读条目模板

人工打开原文核对后，复制下面模板到对应月份文件中（`reading/YYYY/MM.md`）。允许当期零篇，不为凑数收录。完成评审后同步候选状态；自动 RSS 内容不能直接充当已验证结论。

```md
### 文章标题

- 链接：
- 来源：
- 日期：
- 本次阅读 / 核验日期：
- 主题：Agent / RAG / Coding Agent / Eval / Infra / Multimodal
- 难度：入门 / 中级 / 高级
- 推荐阅读前置：
  - [AI Agent](../../llm/agent.md)
- 推荐理由：
- 摘要：
- 读完应该带走什么：
- 对仓库主线的价值：改变哪个 RAG / Agent 工程选择，或补充哪个已知失败模式？
- 证据边界：作者报告 / 本仓库复验 / 尚未复验；数据和适用条件是什么？
- 最小验证：基线、只改变的变量、成功指标、可能失败的条件；未运行时明确写“验证建议，未执行”。
```

## 写作要求

- 摘要用自己的话写，不整段复制原文。
- 如果文章观点很新或时效性强，需要标注“不一定是长期结论”。
- 如果文章是产品发布，必须说明它对学习路径有什么方法论价值。
- 如果文章只适合高级读者，明确写出前置知识。
- 每条最多链接 2-3 个仓库章节，避免变成链接堆砌。
- 不把作者的实验结果写成本仓库复现结果；不填写未经运行的成本、延迟、正确率。
- 区分发表日期、收录日期和核验日期；历史补录明确标注，不能当作新发布。
- 若无法说明它帮助读者做出什么判断或设计什么实验，暂缓精选并记录原因。
